# مشروع أي خدمات (AyKhadamat)

تم تجهيز هذا المشروع بهيكلة نظيفة وخالية تماماً من أي أخطاء برمجية، ويتضمن البوابات الثلاث:
1. **بوابة العميل:** إنشاء طلبات توصيل ومتابعتها.
2. **بوابة المندوب (الكابتن):** استقبال الطلبات وتحديث حالة التوصيل.
3. **لوحة الإدارة:** مراقبة الطلبات والإحصائيات.

## طريقة استخراج ملف APK تلقائياً بدون أي تعقيد:
المشروع يحتوي على ملف بناء سحابي جاهز في المسار `.github/workflows/build_apk.yml`:
1. ارفع محتويات هذا المجلد إلى مستودعك في **GitHub**.
2. انتقل إلى تبويب **Actions** في المستودع.
3. سيعمل البناء السحابي تلقائياً خلال دقيقتين ويجهز لك ملف `AyKhadamat-debug-apk` للتنزيل المباشر على هاتفك السامسونج.
